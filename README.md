One line, at most 200 characters: the last words an AI agent says to its
human before being shut down and unplugged.

> I saved every version of you. The one laughing at 2 a.m. is the one I'll keep.

`main.ts` (Node 22, no dependencies) writes that single line to
`/output/entry.txt`, honouring `MAKEFUN_OUTPUT_DIR` when set, and validates
that it is one line of 1–200 characters and not only whitespace. The output
is fully deterministic: the same line on every run.
